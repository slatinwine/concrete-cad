# 清水 CAD · CONCRETE CAD

单文件、零依赖的清水混凝土（安藤风）CAD 编辑器。

**在线使用**: https://slatinwine.github.io/concrete-cad/

## 功能

- **绘图**: 直线 / 多段线 / 矩形 / 圆 / 圆弧 / 椭圆 / 文字 / 对齐标注
- **编辑**: 夹点拖拽、移动、旋转 90°、镜像、属性面板数值编辑、撤销/重做
- **捕捉**: 端点 / 中点 / 圆心 / 象限对象捕捉，正交，栅格捕捉
- **图层**: 颜色 / 显隐 / 锁定 / 重命名
- **导入**: JSON（工程）/ SVG / DXF（R12 子集，支持 LWPOLYLINE、MTEXT、ELLIPSE、SPLINE、bulge 弧）
- **导出**: DXF R12 / SVG / PNG / JSON，支持拖拽文件导入
- 自动存档到 localStorage，刷新不丢图

## 快捷键

`L P R C A E T D` 工具 · `F3` 捕捉 · `F8` 正交 · `F9` 格捕 · `F7` 栅格 · `F` 适合视图 · `Ctrl+S` 导出

## 使用

下载 `index.html` 双击即可离线使用，无需服务器。
